> **Somelia** — інтерактивний вебкаталог крафтових сирів та вина з інтелектуальною системою підбору ідеальних гастрономічних пар за смаковими профілями, регіонами походження та балансом кислотності/танінів.

## 🔗 Живі посилання
* **GitHub Pages:** [https://rusincuk.github.io/somelia/](https://rusincuk.github.io/somelia/)
* **Netlify Demo:** [https://somelia.netlify.app](https://somelia.netlify.app)

## 📌 Впроваджені JS-бібліотеки через CDN
* **Swiper.js v11** — сенсорна карусель відгуків сомельє з автопрогортанням та зупинкою при наведенні.
* **Fancybox v5** — модальна галерея винного льоху з 3-кратним зумом та ефектом fade.
* **Typed.js** — інтерактивний ефект машинопису в Hero-секції сайту.

## 🛠 Стек технологій

* CDN jsDelivr
